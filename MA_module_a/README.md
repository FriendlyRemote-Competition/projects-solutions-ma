# Speed Tests — Module A

A collection of web-development exercises focused on **HTML, CSS, JavaScript, animations, layouts, dynamic content, and basic PHP**.

This repository contains several independent tests and exercises. Each test is located in its own directory and can be opened separately from the main `index.html` page.

---

## Test Index

| Test   | Name                         | Description                                                       |
| ------ | ---------------------------- | ----------------------------------------------------------------- |
| **A1** | Olympic Rings                | Creation and animation of the Olympic rings using HTML/CSS.       |
| **A2** | Geometric Animations         | Animated geometric shapes and CSS transformations.                |
| **A3** | Holy Grail Layout            | Implementation of the classic Holy Grail web layout.              |
| **A4** | Bars Animations              | Animated bars and visual effects using CSS.                       |
| **B1** | Gradient Selector            | Interactive gradient selection and manipulation.                  |
| **B2** | Dynamic Content Display      | Display and modification of content dynamically using JavaScript. |
| **B4** | Tabs                         | Interactive tab navigation and content switching.                 |
| **C1** | Login System Using JSON File | Basic PHP login system using a JSON file for storing users.       |
| **C3** | Local Table Data Control     | Managing and modifying table data locally with JavaScript.        |
