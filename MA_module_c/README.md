# Interactive E-Book Reader

A fast and responsive web application built with React and Vite for reading course textbooks with dynamic tracking, customizable reader settings, and full-text search.

## Features

* **Progress Tracking**: section completion state, and overall course progress calculation.
* **Custom Reader Controls**: Dynamic font size, line spacing, and theme switching with `localStorage` persistence.
* **Search & Navigation**: Instant search across all chapters, headings, and content snippets.
* **Bookmarks**: Save important sections for quick reference.
* **Dynamic Asset Loading**: Automatic handling of images using Vite glob imports.
